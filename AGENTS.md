# Keyboard Input Regression Guidance

Before changing terminal keyboard input, PTY-to-frontend delivery, or session snapshotting, read and follow `CLAUDE.md` in the repository root. It is the canonical record and regression-prevention guide for the keyboard input loss incident resolved on 2026-08-01.

Do not treat only one part of the documented input workaround as independently removable. Re-read `CLAUDE.md` whenever it changes.
