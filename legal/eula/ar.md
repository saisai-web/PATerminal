# اتفاقية ترخيص المستخدم النهائي لـ PATerminal ‏(EULA) — ترجمة عربية مرجعية

> **بشأن هذه الترجمة:** يُقدَّم هذا النص كترجمة مرجعية للتيسير فقط، وليس النسخة الملزمة قانونًا. النسخة الرسمية الوحيدة هي ملف [`LICENSE.md`](../../LICENSE.md) باللغة الإنجليزية. إذا تعارضت هذه الترجمة مع النص الإنجليزي أو اختلفت عنه، يسود النص الإنجليزي بالقدر الذي يسمح به القانون المعمول به.

**الإصدار 1.0**

**تاريخ السريان: 24 أغسطس 2026**

## 1. الاتفاق والنطاق

اتفاقية ترخيص المستخدم النهائي هذه («EULA») هي اتفاق بينك وبين مشغّل PATerminal («المرخِّص»)، ويمكن التواصل معه على k-saiki@yotsuba-system.co.jp. وتنطبق على الملفات الثنائية الرسمية لـ PATerminal وتحديثاته ووثائقه، وعلى الشفرة المصدرية التي أنشأها PATerminal والمتاحة في المستودع العام (ويُشار إليها مجتمعةً باسم «البرنامج»).

بتنزيل البرنامج أو تثبيته أو نسخه أو بنائه أو تعديله أو استخدامه، فإنك تقبل الإصدار 1.0 من هذه الاتفاقية. تُعالج المبيعات والاشتراكات والإلغاء والمبالغ المستردة بصورة منفصلة في شروط الخدمة وشروط الدفع لدى Polar؛ وترد معالجة البيانات في سياسة الخصوصية.

## 2. الملكية وحالة إتاحة المصدر

PATerminal برنامج مملوك مع شفرة مصدر متاحة، وليس برنامجًا مفتوح المصدر. باستثناء الحقوق المحدودة الممنوحة صراحةً أدناه، يحتفظ المرخِّص بجميع الحقوق والملكية والمصالح في الشفرة التي أنشأها PATerminal والملفات الثنائية الرسمية والوثائق والأسماء والشعارات والمواد الأخرى.

إن إتاحة الشفرة المصدرية للعرض في مستودع GitHub عام لا تمنح إذنًا بإعادة توزيع البرنامج أو بيعه أو ترخيصه من الباطن أو استضافته أو دمجه في منتج أو خدمة أخرى. يجوز لمستخدمي GitHub عرض المستودع واستخدام وظيفة Fork المدمجة بالقدر الذي تتطلبه شروط GitHub.

## 3. الملفات الثنائية الرسمية والاستخدام المدفوع

خلال فترة تجريبية متاحة، يجوز لك استخدام الملفات الثنائية الرسمية للتقييم وفقًا لهذه الاتفاقية. بعد انتهاء التجربة، قد تُقيَّد الميزات ما لم يكن لديك اشتراك مدفوع نشط. تُخصَّص الخطة الفردية لشخص واحد ويمكن تفعيلها على ما يصل إلى ثلاثة أجهزة. وتتطلب خطة Team مقعدًا مخصصًا لكل شخص، وبحد أقصى ثلاثة أجهزة لكل شخص مخصص له مقعد.

يتطلب الاستخدام التجاري أو المهني أو المرتبط بالعمل أو المدرّ للدخل أو أي استخدام تجاري آخر، سواء للملفات الثنائية الرسمية أو للنسخ التي تبنيها بنفسك، ترخيصًا مدفوعًا مناسبًا ما لم يمنح المرخِّص إذنًا كتابيًا مسبقًا.

## 4. ترخيص مجاني للبناء الشخصي

مع مراعاة هذه الاتفاقية، يمنح المرخِّص الفرد ترخيصًا محدودًا وقابلًا للإلغاء وغير حصري وغير قابل للتحويل لنسخ الشفرة المصدرية التي أنشأها PATerminal وتعديلها وبنائها حصريًا للاستخدام الشخصي غير التجاري لذلك الفرد.

لا يشمل هذا الإذن الاستخدام لصالح شركة أو صاحب عمل أو عميل أو منظمة أو فريق أو مشروع مدفوع أو بحث تجاري أو خدمة مقدمة لشخص آخر. كما لا يسمح بتوزيع أرشيفات المصدر أو الملفات الثنائية أو برامج التثبيت أو النسخ المعدلة.

## 5. القيود

باستثناء الحالات التي يمنع فيها القانون المعمول به هذا القيد صراحةً، لا يجوز لك:

- إعادة توزيع الملفات الثنائية الرسمية أو المبنية ذاتيًا أو برامج التثبيت أو أرشيفات المصدر أو النسخ المعدلة، أو نشرها أو بيعها أو تأجيرها أو ترخيصها من الباطن أو نقلها أو تقديمها إلى شخص آخر؛
- تقديم البرنامج أو نسخة معدلة منه كمنتج مستضاف أو مُدار أو مضمّن أو بعلامة بيضاء أو كبرنامج كخدمة؛
- مشاركة مفتاح ترخيص أو تفعيل أو حساب أو مقعد أو بيعه أو نقله أو إساءة استخدامه؛
- تجاوز التحقق من الترخيص أو حدود التجربة أو التفعيل أو تدابير الحماية التقنية أو ضوابط الوصول، أو محاولة تجاوزها؛
- إزالة إشعارات الملكية أو حقوق النشر أو الإسناد أو إشعارات الأطراف الثالثة؛
- استخدام أسماء PATerminal أو شعاراته أو علاماته على نحو يوحي بالتأييد أو بأنه بناء رسمي؛ أو
- استخدام البرنامج بما يخالف القانون أو حقوق أي شخص آخر.

## 6. التعديلات والمساهمات

يظل أي تعديل شخصي مسموح به خاضعًا لهذه الاتفاقية ولا يجوز تقديمه على أنه إصدار رسمي من PATerminal. لا يُوعَد بالدعم أو التوافق أو التوقيع أو التوثيق أو خدمة التحديث أو الصيانة الأمنية لأي نسخة مبنية ذاتيًا أو معدلة.

لا تمنح هذه الاتفاقية وحدها المرخِّص حق استخدام الشفرة التي تقدمها. لا تُقبل المساهمات إلا وفق شروط المساهمين المذكورة في المستودع العام وقت التقديم.

يجوز للمرخِّص تقديم التحديثات أو الميزات أو التوافق أو الخدمات أو تغييرها أو إيقافها. قد يتطلب التحديث قبول اتفاقية أحدث عند تغيير شروط ترخيص جوهرية. ويجوز نشر تصحيحات طفيفة لا تغيّر الحقوق بصورة جوهرية دون طلب موافقة متجددة، مع مراعاة القانون المعمول به.

## 8. برامج الأطراف الثالثة

يتضمن البرنامج برامج مفتوحة المصدر من أطراف ثالثة ومواد أخرى تحكمها إشعارات الترخيص الخاصة بها. تسري تلك التراخيص على مكوناتها، ولا تقلل هذه الاتفاقية الحقوق الممنوحة بموجبها. ينبغي مراجعة إشعارات الأطراف الثالثة المرفقة بالبرنامج والمستودع العام.

## 9. البيانات والأدوات الخارجية

يشغّل PATerminal أغلفة الأوامر ووكلاء سطر الأوامر وأدوات Git والبرامج الأخرى التي تختارها. ولهذه البرامج والخدمات شروطها الخاصة وقد تصل إلى الملفات أو الشبكات أو بيانات الاعتماد أو واجهات API مدفوعة. أنت مسؤول عن مراجعة إجراءاتها والحفاظ على نسخ احتياطية. ترد معالجة PATerminal لبياناته في سياسة الخصوصية.

## 10. المدة والإنهاء

تستمر هذه الاتفاقية حتى إنهائها. تنتهي حقوقك بموجبها تلقائيًا إذا أخللت بها إخلالًا جوهريًا ولم تُصلح إخلالًا قابلًا للإصلاح بعد إشعارك ومنحك فرصة معقولة. عند الإنهاء، يجب أن تتوقف عن استخدام النسخ التي انتهت حقوقك فيها وتحذفها، إلا إذا تطلب القانون المعمول به خلاف ذلك. تبقى أحكام الملكية والقيود وإخلاء المسؤولية والمسؤولية وتسوية المنازعات سارية بعد الإنهاء.
