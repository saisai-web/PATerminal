# ข้อตกลงสิทธิ์การใช้งานสำหรับผู้ใช้ปลายทางของ PATerminal (EULA) — คำแปลภาษาไทยเพื่อใช้อ้างอิง

> **เกี่ยวกับคำแปลนี้:** ข้อความนี้จัดทำขึ้นเป็นคำแปลเพื่อความสะดวกในการอ้างอิงเท่านั้น และไม่ใช่ฉบับที่มีผลผูกพันทางกฎหมาย ฉบับทางการเพียงฉบับเดียวคือ [`LICENSE.md`](../../LICENSE.md) ภาษาอังกฤษ หากคำแปลนี้ขัดแย้งหรือแตกต่างจากภาษาอังกฤษ ให้ใช้ข้อความภาษาอังกฤษเป็นหลักเท่าที่กฎหมายที่ใช้บังคับอนุญาต

**เวอร์ชัน 1.0**

**วันที่มีผล: 24 สิงหาคม 2026**

## 1. ข้อตกลงและขอบเขต

ข้อตกลงสิทธิ์การใช้งานสำหรับผู้ใช้ปลายทางฉบับนี้ (“EULA”) เป็นข้อตกลงระหว่างคุณกับผู้ดำเนินการ PATerminal (“ผู้ให้สิทธิ์”) ซึ่งติดต่อได้ที่ k-saiki@yotsuba-system.co.jp ข้อตกลงนี้ใช้กับไบนารีทางการ การอัปเดต และเอกสารของ PATerminal ตลอดจนซอร์สโค้ดที่ PATerminal จัดทำและเผยแพร่ในที่เก็บสาธารณะ (รวมเรียกว่า “ซอฟต์แวร์”)

การดาวน์โหลด ติดตั้ง คัดลอก สร้าง แก้ไข หรือใช้ซอฟต์แวร์ ถือว่าคุณยอมรับ EULA เวอร์ชัน 1.0 นี้ การขาย การสมัครสมาชิก การยกเลิก และการคืนเงินกำหนดไว้แยกต่างหากในข้อกำหนดการให้บริการและข้อกำหนดการชำระเงินของ Polar ส่วนการประมวลผลข้อมูลอธิบายไว้ในนโยบายความเป็นส่วนตัว

## 2. กรรมสิทธิ์และสถานะ source-available

PATerminal เป็นซอฟต์แวร์กรรมสิทธิ์ที่เปิดให้ดูซอร์สโค้ดได้ และไม่ใช่ซอฟต์แวร์โอเพนซอร์ส นอกจากสิทธิ์ที่จำกัดซึ่งให้ไว้อย่างชัดแจ้งด้านล่าง ผู้ให้สิทธิ์ยังคงถือสิทธิ์ กรรมสิทธิ์ และผลประโยชน์ทั้งหมดในโค้ดที่ PATerminal จัดทำ ไบนารีทางการ เอกสาร ชื่อ โลโก้ และเนื้อหาอื่น

การมองเห็นซอร์สโค้ดในที่เก็บ GitHub สาธารณะไม่ได้อนุญาตให้แจกจ่ายต่อ ขาย ให้สิทธิ์ช่วง โฮสต์ หรือนำซอฟต์แวร์ไปรวมในผลิตภัณฑ์หรือบริการอื่น ผู้ใช้ GitHub อาจดูที่เก็บและใช้ฟังก์ชัน Fork ที่มีอยู่ใน GitHub เท่าที่ข้อกำหนดของ GitHub กำหนด

## 3. ไบนารีทางการและการใช้งานแบบชำระเงิน

ในช่วงทดลองที่มีให้ คุณอาจใช้ไบนารีทางการเพื่อประเมินผลภายใต้ EULA นี้ หลังช่วงทดลอง ฟังก์ชันอาจถูกจำกัดหากไม่มีแผนแบบชำระเงินที่ใช้งานอยู่ แผนบุคคลกำหนดให้หนึ่งคนและเปิดใช้งานได้สูงสุดสามอุปกรณ์ แผน Team ต้องมีหนึ่งที่นั่งต่อคน และแต่ละคนที่ได้รับที่นั่งใช้ได้สูงสุดสามอุปกรณ์

การใช้ไบนารีทางการหรือสำเนาที่สร้างเองเพื่อธุรกิจ วิชาชีพ การจ้างงาน การสร้างรายได้ หรือวัตถุประสงค์เชิงพาณิชย์อื่น ต้องมีสิทธิ์การใช้งานแบบชำระเงินที่เกี่ยวข้อง เว้นแต่ผู้ให้สิทธิ์จะอนุญาตเป็นลายลักษณ์อักษรล่วงหน้า

## 4. สิทธิ์ฟรีสำหรับการสร้างใช้ส่วนบุคคล

ภายใต้ EULA นี้ ผู้ให้สิทธิ์ให้สิทธิ์ที่จำกัด เพิกถอนได้ ไม่ผูกขาด และโอนไม่ได้แก่บุคคล เพื่อคัดลอก แก้ไข และสร้างซอร์สโค้ดที่ PATerminal จัดทำ สำหรับการใช้งานส่วนบุคคลที่ไม่ใช่เชิงพาณิชย์ของบุคคลนั้นเท่านั้น

สิทธิ์นี้ไม่ครอบคลุมการใช้เพื่อหรือในนามของบริษัท นายจ้าง ลูกค้า องค์กร ทีม โครงการที่ได้รับค่าตอบแทน งานวิจัยเชิงพาณิชย์ หรือบริการที่เสนอให้บุคคลอื่น และไม่อนุญาตให้แจกจ่ายคลังซอร์ส ไบนารี ตัวติดตั้ง หรือเวอร์ชันที่แก้ไข

## 5. ข้อจำกัด

เว้นแต่กฎหมายที่ใช้บังคับจะห้ามข้อจำกัดนั้นโดยชัดแจ้ง คุณต้องไม่:

- แจกจ่ายต่อ เผยแพร่ ขาย ให้เช่า ให้สิทธิ์ช่วง โอน หรือจัดหาไบนารีทางการ ไบนารีที่สร้างเอง ตัวติดตั้ง คลังซอร์ส หรือเวอร์ชันที่แก้ไขแก่บุคคลอื่น
- เสนอซอฟต์แวร์หรือเวอร์ชันที่แก้ไขในรูปผลิตภัณฑ์แบบโฮสต์ จัดการ ฝังตัว ไวต์เลเบล หรือซอฟต์แวร์เป็นบริการ
- แบ่งปัน ขาย โอน หรือใช้คีย์สิทธิ์ การเปิดใช้งาน บัญชี หรือที่นั่งโดยมิชอบ
- หลีกเลี่ยงหรือพยายามหลีกเลี่ยงการตรวจสอบสิทธิ์ ขีดจำกัดการทดลองหรือการเปิดใช้งาน มาตรการป้องกันทางเทคนิค หรือการควบคุมการเข้าถึง
- ลบประกาศกรรมสิทธิ์ ลิขสิทธิ์ การระบุที่มา หรือประกาศของบุคคลที่สาม
- ใช้ชื่อ โลโก้ หรือแบรนด์ PATerminal ในลักษณะที่สื่อว่าได้รับการรับรองหรือเป็นบิลด์ทางการ หรือ
- ใช้ซอฟต์แวร์โดยฝ่าฝืนกฎหมายหรือสิทธิ์ของบุคคลอื่น

## 6. การแก้ไขและการมีส่วนร่วม

การแก้ไขเพื่อใช้ส่วนบุคคลที่ได้รับอนุญาตยังคงอยู่ภายใต้ EULA นี้ และห้ามนำเสนอว่าเป็นรุ่นทางการของ PATerminal ไม่มีการรับประกันการสนับสนุน ความเข้ากันได้ การลงนาม การรับรอง บริการอัปเดต หรือการบำรุงรักษาความปลอดภัยสำหรับสำเนาที่สร้างเองหรือแก้ไข

EULA นี้เพียงอย่างเดียวไม่ได้ให้สิทธิ์แก่ผู้ให้สิทธิ์ในการใช้โค้ดที่คุณส่ง การมีส่วนร่วมจะรับเฉพาะภายใต้ข้อกำหนดสำหรับผู้ร่วมพัฒนาที่ระบุในที่เก็บสาธารณะ ณ เวลาที่ส่ง

## 7. การอัปเดตและการเปลี่ยนแปลง

ผู้ให้สิทธิ์อาจให้ เปลี่ยน หรือยุติการอัปเดต ฟังก์ชัน ความเข้ากันได้ หรือบริการ การอัปเดตอาจกำหนดให้ยอมรับ EULA ที่มีผลฉบับใหม่กว่าเมื่อเงื่อนไขสิทธิ์ที่สำคัญเปลี่ยนไป การแก้ไขเล็กน้อยที่ไม่เปลี่ยนสิทธิ์อย่างมีนัยสำคัญอาจเผยแพร่โดยไม่ต้องยอมรับใหม่ ทั้งนี้ตามกฎหมายที่ใช้บังคับ

## 8. ซอฟต์แวร์ของบุคคลที่สาม

ซอฟต์แวร์มีซอฟต์แวร์โอเพนซอร์สของบุคคลที่สามและเนื้อหาอื่นที่อยู่ภายใต้ประกาศสิทธิ์ของตนเอง สิทธิ์เหล่านั้นใช้กับส่วนประกอบของบุคคลที่สาม และ EULA นี้ไม่ลดสิทธิ์ที่ได้รับจากสิทธิ์ดังกล่าว ควรตรวจสอบประกาศของบุคคลที่สามที่มาพร้อมซอฟต์แวร์และที่เก็บสาธารณะ

## 9. ข้อมูลและเครื่องมือภายนอก

PATerminal เรียกใช้ shell เอเจนต์บรรทัดคำสั่ง เครื่องมือ Git และโปรแกรมอื่นที่คุณเลือก โปรแกรมและบริการเหล่านั้นมีเงื่อนไขของตนเอง และอาจเข้าถึงไฟล์ เครือข่าย ข้อมูลรับรอง หรือ API แบบชำระเงิน คุณมีหน้าที่ตรวจสอบการทำงานและเก็บข้อมูลสำรอง การประมวลผลข้อมูลของ PATerminal เองอธิบายไว้ในนโยบายความเป็นส่วนตัว

## 10. ระยะเวลาและการสิ้นสุด

EULA นี้มีผลจนกว่าจะสิ้นสุด สิทธิ์ของคุณสิ้นสุดโดยอัตโนมัติหากคุณละเมิดอย่างมีนัยสำคัญและไม่แก้ไขการละเมิดที่แก้ไขได้ภายหลังได้รับแจ้งและโอกาสอันสมควร เมื่อสิ้นสุด คุณต้องหยุดใช้และลบสำเนาที่สิทธิ์สิ้นสุด เว้นแต่กฎหมายที่ใช้บังคับจะกำหนดเป็นอย่างอื่น ข้อกำหนดเกี่ยวกับกรรมสิทธิ์ ข้อจำกัด การปฏิเสธความรับผิด ความรับผิด และการระงับข้อพิพาทยังคงมีผลหลังสิ้นสุด

## 11. การปฏิเสธการรับประกัน

เท่าที่กฎหมายที่ใช้บังคับอนุญาตสูงสุด ซอฟต์แวร์ให้บริการ “ตามสภาพ” และ “ตามที่มี” โดยไม่มีการรับประกันโดยชัดแจ้ง โดยนัย หรือตามกฎหมาย รวมถึงความสามารถในการจำหน่าย ความเหมาะสมสำหรับวัตถุประสงค์เฉพาะ กรรมสิทธิ์ การไม่ละเมิด ความพร้อมใช้งาน หรือการทำงานที่ปราศจากข้อผิดพลาด EULA นี้ไม่ตัดการรับประกันหรือการเยียวยาที่กฎหมายไม่อนุญาตให้ตัด

## 12. การจำกัดความรับผิดและสิทธิ์ผู้บริโภค

เท่าที่กฎหมายที่ใช้บังคับอนุญาตสูงสุด ผู้ให้สิทธิ์ไม่รับผิดชอบต่อความเสียหายทางอ้อม โดยบังเอิญ พิเศษ เป็นผลสืบเนื่อง เป็นแบบอย่าง หรือเชิงลงโทษ หรือการสูญเสียข้อมูล กำไร รายได้ ธุรกิจ หรือโอกาสที่เกิดจากซอฟต์แวร์ ภายใต้กฎหมายที่ไม่อาจตัดออก ความรับผิดรวมจะไม่เกินจำนวนเงินที่คุณชำระสำหรับ PATerminal ในช่วงสิบสองเดือนก่อนเหตุการณ์ที่ทำให้เกิดข้อเรียกร้อง

ไม่มีส่วนใดใน EULA นี้จำกัดความรับผิดจากการฉ้อโกง การกระทำผิดโดยเจตนา ความประมาทเลินเล่ออย่างร้ายแรง การเสียชีวิตหรือบาดเจ็บที่ไม่อาจจำกัดความรับผิดได้ หรือสิทธิ์และการเยียวยาผู้บริโภคภาคบังคับในเขตอำนาจของคุณ

## 13. กฎหมายที่ใช้บังคับ ภาษา และการติดต่อ

EULA นี้อยู่ภายใต้กฎหมายญี่ปุ่น โดยไม่คำนึงถึงหลักการขัดกันแห่งกฎหมาย และข้อพิพาทอยู่ภายใต้ศาลญี่ปุ่น เว้นแต่กฎหมายภาคบังคับให้ศาลหรือการคุ้มครองอื่นแก่คุณ

ข้อความภาษาอังกฤษเป็นฉบับทางการเพียงฉบับเดียว คำแปลภาษาไทยนี้มีไว้เพื่ออ้างอิงเท่านั้น หากความหมายขัดแย้งกัน ให้ใช้ภาษาอังกฤษเป็นหลักเท่าที่กฎหมายอนุญาต คำถามและคำขออนุญาตเป็นลายลักษณ์อักษรสำหรับการใช้เชิงพาณิชย์หรือการแจกจ่ายต่อ: k-saiki@yotsuba-system.co.jp
